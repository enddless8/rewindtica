# Rewindtica

Rewindtica is a modified typeface derived from Unbounded.

Original typeface: Unbounded  
Original authors: The Unbounded Project Authors  
Modifications: © 2026 enddless8

Rewindtica v0.1 includes Light (300), Medium (500), and Bold (700).
